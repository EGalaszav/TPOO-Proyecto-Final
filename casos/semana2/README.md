# Casos – Semana 2: conflictos y Pull Requests

## Caso 2.1 – Resolución de conflictos
Trabajen en pareja sobre `Calculadora.java`.
1. Integrante A crea `feature/suma-doble` y cambia el cuerpo de `sumar`.
2. Integrante B crea `feature/suma-validada` y cambia la **misma línea** de `sumar`.
3. Se fusiona la rama de A en `main`; luego la de B genera un conflicto.
4. Resolver el conflicto dejando una versión final coherente y hacer commit.

**Evidencia:** captura del conflicto y del commit de resolución.

## Caso 2.2 – Pull Request
1. Cada integrante crea una rama `feature/<nombre>-aporte`.
2. Agrega una línea con su nombre en la tabla de integrantes del `README.md` principal.
3. Hace `push` y abre un Pull Request hacia `main`.
4. Otro integrante revisa el PR (comentario en *Files changed*) y lo aprueba.

**Evidencia:** enlace al Pull Request con la revisión.
